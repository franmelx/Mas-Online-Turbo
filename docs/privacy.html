Política de privacidad de MasOnline Turbo

Última actualización: 13 de septiembre de 2026.

MasOnline Turbo es una extensión independiente y no oficial. Funciona exclusivamente en https://www.masonline.com.ar/.

Datos procesados

Para reducir solicitudes redundantes, procesa local y temporalmente contenido y recursos técnicos de ese sitio: URLs y respuestas GraphQL del catálogo, identificadores de productos y SKU, precios, disponibilidad, vendedor, región comercial y contadores agregados de solicitudes. También compara de forma opaca las cookies vtex_segment y vtex_session para detectar cambios de región o sesión e invalidar inmediatamente la caché anterior; no las decodifica, registra ni transmite.

No solicita, recopila ni almacena contraseñas, medios de pago o datos introducidos durante el checkout. Las mutaciones de autenticación, carrito y checkout no se cachean ni se sustituyen.

Uso y almacenamiento

  • Los datos del catálogo permanecen temporalmente en la memoria de la pestaña y expiran automáticamente.
  • Las preferencias se guardan localmente y las métricas se separan por pestaña mediante el almacenamiento del navegador.
  • No existe un servidor del desarrollador, telemetría externa, venta de datos ni perfiles publicitarios.
  • Ninguna información se comparte entre usuarios.

Uso limitado

El uso de la información recibida cumple la Política de Datos de Usuario de Chrome Web Store, incluidos sus requisitos de Uso Limitado. Los datos se utilizan únicamente para la función visible de mejorar el rendimiento del catálogo. No se venden, no se usan para publicidad, evaluación crediticia ni otros fines ajenos, no se transfieren a terceros y ninguna persona puede acceder a ellos desde el desarrollador.

Permisos

storage: conserva preferencias y métricas locales. masonline.com.ar: ejecuta las optimizaciones únicamente en el sitio compatible.

Control y contacto

El usuario puede desactivar módulos o vaciar cachés desde el panel. Al desinstalar la extensión, el navegador elimina sus datos almacenados.
