# Seguridad

No publiques cookies, identificadores de sesión, direcciones, datos del carrito,
capturas del checkout ni información de pago en un issue.

Para reportar una vulnerabilidad, usa el reporte privado de seguridad del
repositorio en GitHub. Incluye la versión, el navegador, el impacto y los pasos
mínimos para reproducirla con datos ficticios.

Las fallas normales de rendimiento o interfaz pueden informarse mediante:
<https://github.com/franmelx/Mas-Online-Turbo/issues>
